# 🎤 Seshanba Kungi Imtihon Himoyasi va Tushuntirish Matni

Ushbu hujjat imtihon topshirig‘i bo‘yicha **“Qaysi vositadan foydalandim, qanday qildim?”** savoliga tayyor professional hisobot va seshanba kuni o‘qituvchi hamda guruh oldida loyihani taqdim qilish nutqidir.

---

## 📌 1. Guruhga / O‘qituvchiga Yuborish Uchun Qisqa Xabar (Telegram uchun)

```text
Assalomu alaykum! 

🏠 Imtihon topshirig‘i: Uyni masofadan ko‘rish uchun 360° Virtual Sayohat (Virtual Tour).

🔹 Qaysi vositadan foydalandim:
- JavaScript (WebGL) va Pannellum 360° dvigateli;
- HTML5, zamonaviy CSS3 (Glassmorphism dizayn, CSS Grid/Flexbox);
- Vektorli arxitektura chizmasi (SVG Minimap);
- Web Audio API (interaktiv tovush effektlari sintezi);
- Python (panoramalarni 2560x1280 veb-formatga optimallashtirish va mahalliy server).

🔹 Qanday qildim:
1. Uydagi 4 ta asosiy hudud (Mehmonxona, Oshxona, Yotoqxona, Vanna xonasi) uchun yuqori sifatli 360° ekvirektangulyar panoramalar tayyorlandi.
2. Har bir xona o‘rtasida xaridor bemalol sayr qilishi uchun 3D yo‘nalish ko‘rsatuvchi eshik/o‘tish hotspotlari joylashtirildi.
3. Mebel va qulayliklar ustiga ma’lumot beruvchi interaktiv “Info” tugmalari o‘rnatildi.
4. Ekranning burchagida xaridor qaysi xonada turganini ko‘rsatuvchi va bir bosishda kerakli xonaga eltuvchi 2D interaktiv Qavat Rejasi (Minimap) integratsiya qilindi.
5. Uy narxi ($125,000), maydoni (110 m²) va rieltor bilan bog‘lanish ma’lumotlari kiritildi.
6. Telefon va kompyuter ekranlariga to‘liq moslashtirildi (responsive).

📸 Ilovada: 3 ta skrinshot va loyihaning to‘liq kodi.
```

## 🎙️ 2. Seshanba Kuni Jonli Taqdimot Nutqi (2–3 daqiqalik taqdimot rejasi)

### 1-qadam: Kirish (Muammo va yechim)
> *"Assalomu alaykum, hurmatli ustoz va guruhdoshlar!  
> Tasavvur qiling, Toshkent City hududida premium kvartira sotilyapti. Xaridorlar viloyatda yoki chet elda bo‘lishi, yoxud tirbandlik sababli har safar kelib ko‘rishga vaqti yetmasligi mumkin.  
> Mening maqsadim — xaridorga shunchaki rasmlar emas, balki telefon yoki kompyuter orqali xuddi o‘zi uy ichida yurgandek his beruvchi zamonaviy 360° virtual sayohat yaratish bo‘ldi."*

### 2-qadam: Ko‘rsatib berish (Demonstratsiya)
*(Bu paytda brauzerda loyihani ochib ko‘rsatasiz)*
1. **Mehmonxona (Living room):**  
   > *"Mana hozir biz mehmonxonadamiz. Sichqoncha orqali atrofni 360 daraja burib ko‘rishimiz mumkin. Mana bu yerdagi ko‘rsatkichni bossak, oshxonaga o‘tamiz."*
2. **Oshxona (Kitchen):**  
   > *"Oshxonaga o‘tdik. Mebeldagi axborot belgisini bossak, Bosch texnikasi va kvarsit orolcha stoli haqida aniq parametrlar chiqadi."*
3. **Qavat rejasi (Minimap):**  
   > *"O‘ng tomonda uyning 2D arxitektura rejasi bor. Men yotoqxonaning ustiga bossam, to‘g‘ridan-to‘g‘ri yotoqxonaga olib o‘tadi."*
4. **Vanna xonasi (Bathroom):**  
   > *"Vanna xonasi ham qamrab olingan — jami 4 ta xona mavjud."*
5. **Uy haqida ma’lumot va Aloqa:**  
   > *"'Uy haqida' tugmasini bosganda kvartira narxi, umumiy maydoni va agent bilan qo‘ng‘iroq yoki Telegram orqali bog‘lanish tugmalari ochiladi."*

### 3-qadam: Texnik tomondan tushuntirish
> *"Texnik jihatdan bu loyiha WebGL asosidagi engil va tezkor Pannellum kutubxonasi yordamida qurildi. Rasmlar hajmi 40 MB dan 300-500 KB ga optimallashtirilgan, shuning uchun hatto mobil internetda ham bir zumda yuklanadi. Tovushlar Web Audio API orqali brauzerning o‘zida dinamik hosil qilinadi."*

## 🌐 3. Loyihani Internetga Bepul Joylash (Jonli Havola Olish)

Imtihon shartida **"ishlaydigan havola"** talab qilingan. Buni 1 daqiqada quyidagi bepul xizmatlarga yuklab havola olish mumkin:

### A varianti: GitHub Pages orqali
1. [github.com](https://github.com) saytida yangi repo oching (masalan, `virtual-tour`).
2. Loyihadagi barcha fayllarni (`index.html`, `style.css`, `app.js`, `assets/`) unga yuklang.
3. GitHub reponing **Settings** -> **Pages** bo‘limiga kiring.
4. **Branch: main** -> **Save** tugmasini bosing.
5. 1 daqiqa ichida sizga jonli havola beriladi: `https://username.github.io/virtual-tour/`

### B varianti: Netlify Drop orqali (Kod yozmasdan, 30 soniyada)
1. [app.netlify.com/drop](https://app.netlify.com/drop) saytiga kiring.
2. `2-dars` papkasini sichqoncha bilan ushlab, brauzerdagi oynaga tashlang (drag & drop).
3. Sayt bir necha soniyada ishga tushadi va sizga tayyor havola beradi (masalan, `https://toshkent-city-tour.netlify.app`).

### C varianti: Vercel orqali
1. [vercel.com](https://vercel.com) orqali GitHub reponi ulab darhol deploy qiling.
